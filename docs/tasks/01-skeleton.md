## Задача
Създай скелета на проекта: backend със слоевете, два сайта с Vite (магазин и админ панел), Docker файлове и docker-compose, така че всичко да стартира с една команда.

## Контекст
- Правилата са в CLAUDE.md, стекът и обхватът са в docs/requirements.md.
- Структурата на папките е като в раздела за структурата на репото в docs/project-start.md.
- Проектите на backend се казват Storefront.*, не Printko.*.

## Критерии за приемане
- `docker compose up` стартира PostgreSQL, API, магазин и админ панел, без ръчни стъпки освен копирането на `.env.example` в `.env`.
- GET /health на API връща 200 и проверява връзката с базата.
- Магазинът и админ панелът показват дали API е достъпно, като извикват /health.
- Backend има четирите проекта и двата тестови проекта, а зависимостите между тях следват правилата в CLAUDE.md.
- Има един модулен тест и един интеграционен тест за /health с Testcontainers.
- Dockerfile-овете са многоетапни, без root потребител и с фиксирани версии на базовите образи.
- README описва как се стартира проектът и как се пускат тестовете.
- Форматирането и linter-ът минават без предупреждения.

## Граници
- Без модел на домейна, миграции и автентикация.
- Нови пакети: само тези, които идват с шаблоните на xUnit и Vite, плюс Testcontainers, Vitest, Testing Library, ESLint и Prettier. За всичко друго питай.
- Не променяй папката docs и файла CLAUDE.md.

## Как се проверява
dotnet build, dotnet test, npm run lint, npm test, docker compose up --build и ръчна проверка в браузъра.

## Преди да пишеш код
Дай кратък план и списък с предположенията си.
