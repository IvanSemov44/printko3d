# 0008. Книгата на Code Maze е справочник за стила на кода

Дата: 2026-11-06
Статус: прието

## Контекст
Решение 0006 вече избра слоевете и контролерите по „Ultimate ASP.NET Core Web API“ на Code Maze. Остава да е ясно как се ползва книгата в по-малките въпроси (рутиране, филтри, страниране, грешки), където тя понякога се различава от `CLAUDE.md`.

## Решение
Книгата е справочник за стила и структурата. При конфликт с `CLAUDE.md` важи `CLAUDE.md`.

**Вземаме от книгата**
- Слоеве: repository-та, `IRepositoryManager`, услуги, тънки контролери (вече е така).
- Базови изключения `NotFoundException` и `BadRequestException` и един глобален обработчик.
- Action filters за общите проверки на входа.
- Помощни методи в услугите, които събират повтарящите се проверки за съществуване.
- Общ базов клас на параметрите на заявките (`page`, `pageSize`, `sort`), с максимум на страницата, който се пази на сървъра.
- Филтриране, търсене и подреждане като extension методи на `IQueryable`.
- Конвенции: атрибутно рутиране, `204` за PUT и DELETE, `CreatedAtRoute` за POST, DTO като `record`.

**Променяме спрямо книгата**

| В книгата | При нас |
| --- | --- |
| Собствен `ErrorDetails` | `ProblemDetails` |
| Методи без `CancellationToken` | `async` навсякъде с `CancellationToken` |
| Страниране с хедър `X-Pagination` | Тяло `{ items, page, pageSize, totalCount, totalPages }` |
| `PagedList<T>`, който реже в паметта | `Skip`, `Take` и `Count` в базата, със `Select` към DTO |
| Валидация с `ModelState` | Валидация на границата, грешки като `ValidationProblemDetails` |
| AutoMapper | Явно картографиране или `Select` в заявката |
| NLog и `ILoggerManager` | Вграденият `ILogger` със структурирани логове |
| Swashbuckle | Вграденият OpenAPI |

**Не вземаме засега:** CQRS и MediatR, HATEOAS, shaping на полета, Root Document, версиране, кеширане, rate limiting, Identity и JWT, deploy към IIS. Когато някое от тях стане нужно, решава се с отделна задача (вход и права, и rate limiting са по правилата за сигурност, с човешки преглед).

## Последствия
- В бъдещите сесии не е нужно да се обяснява кое от книгата важи.
- Ако книгата и `CLAUDE.md` се разминават в нещо ново, ИИ го казва, вместо да избира сам.
- Нов пакет от книгата (например за rate limiting) пак иска одобрение по `CLAUDE.md`.
