# 0004. Публично GitHub репо до включване на GitHub Pro

Дата: 2026-11-04
Статус: прието

## Контекст
Защитата на клона `main` (задължителен pull request, забрана на force-push) е изискване от `CLAUDE.md`. На безплатния план на GitHub тя работи само за публични репа. Проектът е в началото, има един разработчик и още няма реални данни или тайни.

## Решение
Репото `printko3d` е публично. Когато проектът се доближи до реален магазин, се преминава към GitHub Pro и репото може да стане частно отново. Включени са защитата на `main`, secret scanning с push protection, Dependabot alerts и Dependabot security updates.

## Последствия
- Кодът и документите са видими за всички, затова в репото не влиза нищо тайно, включително в историята на commit-ите.
- Автор на commit-ите е личният имейл на собственика и остава видим. Това е съзнателно решение.
- Защитата на `main` засега не изисква одобрение (един разработчик) и не изисква CI. И двете се добавят с втори човек и след задача 2.
- Преди смяна към частно репо или към истински данни се прави нов преглед на историята за тайни.
