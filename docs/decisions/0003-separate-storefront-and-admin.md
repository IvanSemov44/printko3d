# 0003. Магазин и админ панел като отделни приложения

Дата: 2026-11-04
Статус: прието

## Контекст
Публичният магазин и админ панелът имат различни потребители, различни изисквания за сигурност и различен размер на кода. Общ пакет би зареждал админ кода при всеки клиент.

## Решение
Те са две отделни React приложения в `src/web` (`storefront` и `admin`), с общ пакет `shared` за API клиента, типовете и общите компоненти. Работят през npm workspaces и имат отделни Dockerfile-ове.

## Последствия
- Админ кодът и админ адресът не се зареждат при клиентите и могат да се защитят отделно.
- Общият код стои в `shared` и не се дублира.
- `docker compose up` стартира и двете приложения, заедно с API и базата.
