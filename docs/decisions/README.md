# Записани решения

Тук се записва всяко решение, което променя правилата, архитектурата или обхвата. Един файл на решение, с номер и кратко име, например `0005-hosting-in-bulgaria.md`.

Формат на файла:

```markdown
# <номер>. <кратко заглавие>

Дата: ГГГГ-ММ-ДД
Статус: прието | заменено от <номер>

## Контекст
Какъв проблем решаваме и какви са ограниченията.

## Решение
Какво избираме.

## Последствия
Какво печелим, какво губим и какво се променя.
```
