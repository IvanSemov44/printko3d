# 0001. React SPA с Vite за публичния магазин

Дата: 2026-11-04
Статус: прието

## Контекст
Публичният каталог трябва да се индексира от търсачките. Страници, които се рисуват изцяло в браузъра, се индексират по-бавно от предварително генерираните. От друга страна, SPA е по-проста за разработка и за хостинг, а стекът React и TypeScript е познат на разработчика.

## Решение
Публичният магазин е React SPA, изградена с Vite, без генериране от сървъра.

## Последствия
- За каталога важат допълнителни правила: уникално заглавие и описание за всяка страница, чисти адреси със слъг, карта на сайта и бърз първи екран.
- Ако индексирането се окаже слабо, преминаването към предварително генериране или към Next.js се решава отделно с нов запис.
